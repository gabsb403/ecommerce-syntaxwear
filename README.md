# 🛍️ SyntaxWear - E-commerce de Tênis e Sneakers

Uma loja online moderna e responsiva especializada em tênis e sneakers, desenvolvida com HTML, CSS e componentes reutilizáveis.

![SyntaxWear](./images/favicons/favicon.ico)

## 🌟 Sobre o Projeto

**SyntaxWear** é uma plataforma de e-commerce elegante e funcional focada na venda de tênis e sneakers de alta qualidade. O site oferece uma experiência de compra intuitiva com interface moderna, navegação responsiva e categorias bem definidas.

### ✨ Funcionalidades Principais

- 👟 **Catálogo de Produtos** - Grid responsivo com múltiplas categorias de tênis
- 📱 **Design Responsivo** - Totalmente adaptado para desktop, tablet e mobile
- 🎨 **Interface Moderna** - Design limpo e profissional com animações suaves
- 🔍 **Categorização** - Organização por tipo: Casual, Esporte, Moderno e Futurista
- 👕 **Filtros por Gênero** - Seções dedicadas para Masculino e Feminino
- 📧 **Newsletter** - Formulário para inscrição em comunicados
- 🔗 **Redes Sociais** - Integração com Instagram, WhatsApp, TikTok e Facebook
- 💳 **Carrinho de Compras** - Funcionalidade de compra com interface intuitiva

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica e acessível
- **CSS3** - Layouts responsivos e componentes estilizados
- **Design Responsivo** - Mobile-first approach com media queries
- **Versionamento Git** - Controle de versão integrado

## 📋 Componentes Principais

### Header
- Logo da marca com link para home

## 🚀 Como Usar

### Requisitos
- Navegador moderno (Chrome, Firefox, Safari, Edge)
- Nenhuma dependência externa

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/gabsb403/ecommerce-syntaxwear.git
```

2. Navegue até a pasta do projeto:
```bash
cd ecommerce-syntaxwear
```

3. Abra o arquivo `index.html` no navegador:
   - Duplo clique no arquivo, ou
   - Clique direito → Abrir com → Navegador escolhido, ou
   - Use uma extensão como Live Server no VS Code

## 🎨 Estilos e Design

### Variáveis CSS
O arquivo `variables.css` contém as principais cores, fontes e espaçamentos do projeto, permitindo modificações globais de forma centralizada.

### Sistema de Grid
- Utiliza CSS Grid para layout responsivo
- Media queries para diferentes breakpoints
- Flexbox para componentes internos

### Classe de Botões
- `.btn` - Base para todos os botões
- `.btn-outline` - Estilo com borda
- `.btn-filled` - Estilo preenchido

## 📱 Responsividade

O site é totalmente responsivo e se adapta a diferentes tamanhos de tela:
- **Desktop** - Layout completo com todas as funcionalidades
- **Tablet** - Layout ajustado com navegação otimizada
- **Mobile** - Menu hambúrguer, stack vertical, toque otimizado

## ♿ Acessibilidade

- HTML semântico com tags apropriadas
- Atributos `alt` em todas as imagens
- `aria-label` em ícones e elementos interativos
- Navegação por teclado suportada
- Estrutura lógica de headings
